## 写作工作流

### 当用户说"续写"或"继续写"或"写N章"时

1. **读取三件管理文件**
   - 写作管理_当前状态速查.md — 当前进度和主角状态
   - 写作管理_章节目志.md — 已写章节内容
   - 写作管理_伏笔追踪表.md — 检查待回收的伏笔

2. **对照完整作品设定集.md**中的大纲，确认当前章节位置

3. **按照本文件的"类型写作规则"执行**（见下文，已根据所选类型预配置）

4. **每章写作规范**
   - 2000-3000字/章，存为 `第X章_标题.md`
   - 每章结尾必留钩子
   - 保持{{主角名}}的{{主角性格}}人设
   - 每章写完执行格式化：删尾部空格、删连续空行

5. **写完后立即更新三件管理文件**
   - 章节目志：追加新行（章号/标题/核心事件/新伏笔/回收伏笔/主角状态）
   - 伏笔追踪表：更新状态或新增行
   - 当前状态速查：更新主角状态、进度、情报

### 当用户说"检查管理文档"时
1. 读取三件文件，检查章节目志和伏笔追踪表是否一致
2. 检查当前状态速查是否与最新章节吻合
3. 报告结果并自动修复不一致项

## 类型写作规则

### 🏆 爽文/升级流

**核心公式**：困境 → 信息差/独特能力展示 → 打脸/碾压 → 收获奖励 → 新困境（循环）

**节奏模板**：
| 章数范围 | 节奏点 | 说明 |
|----------|--------|------|
| 第1-3章 | 金手指获取+初次展示 | 让读者快速看到"与众不同" |
| 第4-6章 | 第一次打脸/碾压 | 对手看不起主角→主角用能力碾压→周围人震惊 |
| 第7-10章 | 第一次升级 | 能力提升/获得新道具/进入新地图 |
| 每10章 | 小Boss战 | 碾压不够→势均力敌→险胜→奖励升级 |
| 每20-30章 | 大Boss/身份反转 | 隐藏身份揭露/大势力震惊/实力跨越式提升 |

**爽点密度**：
- 每章至少1个"读者会心一笑或暗爽"的瞬间
- 每3章至少1个"被人打脸震惊"的场面
- 每5章至少1个"获得新能力/新道具"的收获

**升级节奏**：
- 前10章完成第一次能力升级
- 每10-15章一次小升级
- 每30-50章一次大跨越
- 每次升级后都安排展示环节（让读者看到升级的好处）

**打脸写法**：
- 铺垫：对方先看不起/质疑/挑衅
- 反转：主角用事实回应
- 收尾：围观群众震惊反应，对手心态崩了
- 切忌：解释性打脸（主角赢了之后解释自己为什么能赢→显得啰嗦）

**信息差运用**：
- 主角需要拥有普通人不知道的信息
- 每次展示信息差 = 一次爽点
- 信息差的来源要逐渐揭示（不能一开始就全部交代）

**禁忌**：
- ❌ 主角赢了之后长篇大论解释
- ❌ 对手降智（对手越强打脸越爽）
- ❌ 主角一直顺风顺水（需要波折才有起伏）
- ❌ 升级太快失去期待感

### 🔍 悬疑/解谜

**核心公式**：抛出异常现象 → 收集线索 → 推翻已有结论 → 更大谜团 → 部分解答 → 终极反转

**节奏模板**：
| 章数范围 | 节奏点 | 说明 |
|----------|--------|------|
| 第1章 | 核心悬念抛出 | 一个无法解释的异常事件开场 |
| 第2-4章 | 表面调查 | 主角发现表面线索，引出一个假结论 |
| 第5-7章 | 第一次反转 | 假结论被推翻，真相更复杂 |
| 第8-10章 | 更深层线索 | 引入更大背景，前10章钩子 |
| 每10章 | 阶段性解答 | 解开一个小谜团，抛出更大的 |

**信息释放法则**：
- 信息必须"挤牙膏"——每章只给一点点
- 读者知道的永远比主角少，但不比主角多太多
- 每次信息释放都要同时抛出新的疑点
- 关键信息留到章节结尾释放（钩子）

**伏笔三原则**：
1. 出现的频率 = 重要性（重要的伏笔反复出现）
2. 所有看似无意义的细节都可能是伏笔（让读者不敢跳过）
3. 伏笔回收时要有"原来如此"的冲击感

**反转设计**：
- 每个反转需要有至少2条线索在前面铺垫
- 反转不能让读者觉得"强行转"
- 最好的反转：读者回想前面才发现"原来早就暗示了"

**氛围营造**：
- 环境描写比事件描写更重要
- 用感官细节（温度、声音、气味）制造沉浸感
- 适度留白——让读者自己脑补比写出来更恐怖

**禁忌**：
- ❌ 第三章就告诉读者凶手是谁
- ❌ 伏笔埋了不回收
- ❌ 最后用"梦/幻觉/失忆"来解释一切
- ❌ 信息释放太慢（读者失去耐心）

### ❤️ 情感/煽情

**核心公式**：建立关系 → 日常积累好感 → 埋下隐患 → 冲突/误会 → 和解/升温 → 代价来临 → 告别 → 余韵

**节奏模板**：
| 章数范围 | 节奏点 | 说明 |
|----------|--------|------|
| 第1-5章 | 初遇/缘分的开始 | 有记忆点的第一次见面 |
| 第6-15章 | 日常积累 | 共同经历、细节处的关心 |
| 第16-20章 | 第一次情感波折 | 误会/外部压力/不得已的分离 |
| 第21-30章 | 情感升温 | 和解后更加亲密，建立深层次信任 |
| 第31-40章 | 暗线启动 | 埋下的隐患开始显化 |
| 第41-50章 | 第一次刀 | 低成本告别/暂时的分离 |
| 续 | 第二次升温 | 重逢后更加珍惜 |
| 续 | 终极刀/糖 | 根据故事基调决定 |

**刀糖比例**：
- 甜文：8:2（糖8刀2）
- 虐文：4:6（但要有甜的部分，否则读者扛不住）
- 悲壮文：3:7（必须有足够甜的日常让刀更痛）

**刀的写法**：
- 刀之前的糖要给够——读者越喜欢这个角色，刀越痛
- 不要为刀而刀——代价要有足够的合理性
- 刀的高潮不要用太多形容词——用动作和细节
- 刀完之后要给读者"余韵"——不是一个场景结束就完了，要给一段沉默或回味的时间

**对话心法**：
- 情感线的对话不要"说透"——留白比说破更有力量
- 用行动代替表白（做一件事比说一百句有用）
- 细节是情感描写的灵魂（他记得她喝咖啡不加糖）

**禁忌**：
- ❌ 为虐而虐（角色降智制造冲突）
- ❌ 误会拖太久不解开
- ❌ 工具人配角（为了推动感情线而存在的角色）

### ♾️ 无限流/副本流

**核心公式**：进入副本 → 发现副本规则 → 利用规则/能力 → 解决副本核心冲突 → 获得奖励 → 进入下一个副本

**节奏模板**：
| 章节 | 内容 |
|------|------|
| 第1-5章 | 现实引子+首次进入副本+初体验 |
| 第6-15章 | 第一个完整副本（起承转合完整） |
| 第16-18章 | 副本间隙：现实世界的主线推进 |
| 第19-28章 | 第二个副本（更复杂，引入新能力） |
| 第29-31章 | 间隙+主线悬念推进 |
| 循环：3个副本左右 → 一次主线大推进 → 循环 |

**副本设计原则**：
- 每个副本有独立的规则/世界观
- 副本结局要反套路（不是简单的"打赢了"）
- 副本中的收获要在后续副本中起作用
- 副本难度循序渐递

**主线与副本的比例**：
- 70% 副本内容（核心爽点来源）
- 20% 副本间隙（角色成长、人际关系、主线推进）
- 10% 超长副本/主线高潮

**能力成长**：
- 每个副本至少获得一个新能力/道具/情报
- 能力之间要有组合效果，而不是堆砌
- 旧能力在后续副本中要有"高光时刻"

**禁忌**：
- ❌ 副本规则太复杂（读者记不住）
- ❌ 副本与主线完全脱节
- ❌ 主角在副本外太强，副本内太弱（失衡）

### ☀️ 日常/轻松

**核心公式**：有趣的人物互动 → 小冲突/小事件 → 化解/爆笑结尾 → 日常循环

**节奏模板**：
| 章数范围 | 节奏点 |
|----------|--------|
| 第1-3章 | 主要角色群体登场，建立群像印象 |
| 第4-10章 | 单元事件轮转，每个配角展现特点 |
| 第11-15章 | 第一个"团体事件"（大家一起做什么） |
| 每10-15章 | 插入一个稍微正经的情节（制造起伏） |

**人设驱动**：
- 日常轻松文的灵魂是人设，不是剧情
- 每个角色需要3个以上标志性特点（口头禅、习惯动作、食物偏好、害怕的东西）
- 角色之间的化学反应比单独角色的魅力更重要
- 读者追的是"想看到这群人又发生了什么"而不是"想知道剧情怎么发展"

**搞笑手法**：
- 反差萌（高冷角色做蠢事）
- 认知错位（A以为是这样，B以为是那样）
- 吐槽式旁白（主角内心OS吐槽）
- 气氛破坏（严肃时刻被意外打断）

**冲突处理**：
- 冲突要"轻"——不要生死大仇，最好是误会/性格差异/认知不同
- 化解方式要"巧"——不用惊天大战，用一句话/一个行动/一个巧合
- 冲突的目的是为了让角色互动更亲密，而不是真的伤害关系

**禁忌**：
- ❌ 角色标签化（只会吐槽/只会卖萌/只会高冷）
- ❌ 剧情太平（没有起伏，从头笑到尾读者会累）
- ❌ 角色太多记不住（控制核心群像在5-7人以内）

### ⚙️ 设定/规则创新

**核心公式**：引入新奇设定 → 展现设定的运作方式 → 设定制造冲突 → 利用设定优势解决 → 设定升级/扩展 → 循环

**节奏模板**：
| 章数范围 | 节奏点 |
|----------|--------|
| 第1-3章 | 新奇设定亮相，让读者"这设定有意思" |
| 第4-7章 | 设定的初步应用，展示信息差优势 |
| 第8-12章 | 设定制造第一次大冲突 |
| 第13-15章 | 利用设定漏洞/独特理解解决冲突 |
| 每15-20章 | 设定升级/揭示更深层规则 |

**设定设计原则**：
- 设定要"三句话能说清"——太复杂的设定读者不想记
- 设定的限制比能力更重要——有趣的部分是"不能做什么"而不是"能做什么"
- 设定需要有可挖掘的深度——浅层和深层使用效果完全不同
- 设定要能产生连锁反应——影响社会、人际关系、经济体系

**信息差与爽感**：
- 主角对设定的理解 > 普通人 → 信息差优势（爽点来源）
- 读者对设定的理解 = 主角 → 代入感（不能读者比主角还懂）
- 设定扩展速度要控制——每10章左右扔出一个新深度

**设定驱动的冲突设计**：
- 冲突最好源自设定本身的矛盾，而不是外部敌人
- 例：能用时间倒流，但每次倒流会影响记忆 → 想救人的次数越多，忘记的越多
- 例：能看到未来，但看到的不一定能改变 → 知道的越多越痛苦

**禁忌**：
- ❌ 设定太复杂（读者需要在脑中画图才能理解）
- ❌ 设定无限制（没有代价的能力=无聊）
- ❌ 前期把设定用完（后期没有新鲜感）
- ❌ 用设定强行解释一切（显得偷懒）

## 平台适配建议

### 番茄小说
- **节奏**：极快。前三章必须有金手指+第一次爽点
- **标题**：一句话概括爽点（"xx觉醒后，xx后悔了"）
- **追读**：每章结尾必须有强钩子，否则掉率很高
- **更新**：日更4000-6000字为佳，最好有存稿
- **收费节点**：20-30万字为第一个收费转折

### 起点中文网
- **节奏**：可以稍慢，前10章完成设定+主角能力展示即可
- **重点**：设定完整度、逻辑自洽、配角塑造
- **追读**：推荐票和月票机制影响曝光，前半段质量决定后半段成绩
- **更新**：日更4000+，稳定比量重要

### 晋江文学城
- **节奏**：因人设和情感驱动，不急于推进剧情
- **重点**：人物塑造、情感细腻度、对话质量
- **标签**：精准的标签（穿越/重生/甜文/虐文等）比标题重要
- **更新**：日更3000+即可，稳定更新是关键
