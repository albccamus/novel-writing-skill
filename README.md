# Novel Writing Skill

**让 AI 帮你写长篇网文时，不会忘记前面写过什么。**

---

## 它解决什么问题

写长篇最大的痛点不是灵感，是**连贯性**。

- 前面埋的伏笔到后面忘了收
- 配角性格写飘了
- 时间线对不上
- 主角的能力/道具/状态前后不一致

这些问题在长篇连载中几乎不可避免——因为人的记忆是有限的。

这个框架的核心是一套"四文件管理系统"，让 AI 每次写作前先读进度，写完后更新状态。相当于给 AI 装了一个专用记事本。

---

## 快速开始

```bash
# 1. 下载
git clone https://github.com/albccamus/novel-writing-skill.git
cd novel-writing-skill

# 2. 初始化项目
bash scripts/init.sh

# 3. 回答几个问题（书名、主角、选类型...）
#    自动生成 CLAUDE.md + 管理模板 + 设定集骨架

# 4. 开始写
```

---

## 工作流

```
启动 → AI 读取四件管理文件 → 了解当前进度
     → 对照设定集确认位置
     → 按照所选类型的写作规则写 N 章
     → 每章末尾留钩子
     → 更新四件管理文件
     → 格式化 → 完成
```

每次只需要说"续写10章"，剩下的自动执行。

---

## 内置写作类型

不同的小说类型有完全不同的写作规律。框架内置 6 种类型的完整规则，初始化时选一个就行。

| 类型 | 适合平台 | 一句话 |
|------|----------|--------|
| **爽文/升级流** | 番茄、起点 | 打脸要快，升级要稳，信息差碾压 |
| **悬疑/解谜** | 起点、豆瓣 | 信息挤牙膏，伏笔不白埋，反转有铺垫 |
| **情感/煽情** | 晋江、番茄女频 | 糖要甜够，刀要合理，留白比说破有力 |
| **无限流/副本** | 起点、番茄 | 副本独立成章，主线暗中推进 |
| **日常/轻松** | 番茄、晋江 | 人设就是剧情，角色互动决定一切 |
| **设定/规则创新** | 番茄、起点 | 设定的限制比能力更重要 |
| **自定义** | 全部 | 你定规则，AI 按你的规则写 |

每种类型包含：**核心公式 + 节奏模板 + 爽点密度 + 写法技巧 + 禁忌**

## 管理四件套

```
写作管理_章节目志.md       # 每章核心事件 + 伏笔记录
写作管理_伏笔追踪表.md     # 所有伏笔的埋设/回收状态
写作管理_角色关系表.md     # 角色关系、人设、状态变更
写作管理_当前状态速查.md   # 主角状态 + 进度快照
```

四个文件构成小说的"外部记忆"。每次续写，AI 自动读取、写完后自动更新。写累了说一句"检查管理文档"，AI 自己复核四张表是否一致。

```
    ├── 写作管理_角色关系表.md   # 角色关系与人设管理（空白模板）
    ├── 写作管理_当前状态速查.md # 进度快照（空白模板）
    └── .claude/
        └── settings.local.json  # 权限预配
```
