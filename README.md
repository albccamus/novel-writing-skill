# Novel Writing Skill

**一个基于Claude Code的长篇网文续写工具。**
选类型→填设定→说"续写"→AI按该类型的写作手法自动工作。

## 核心理念

不同的小说类型有完全不同的写作规律：

- **爽文的节奏** = 每3章一个打脸，升级不能停
- **悬疑的节奏** = 信息挤牙膏，每章结尾必扔钩子
- **煽情的节奏** = 先给糖再给刀，日常越甜回忆越痛
- **无限流的节奏** = 副本独立起承转合，主线缓慢推进

本工具内置6种主流网文类型的写作规则，你选类型，AI自动适配。

## 快速开始

```bash
# 1. 下载
git clone https://github.com/albccamus/novel-writing-skill.git
cd novel-writing-skill

# 2. 初始化新项目
bash scripts/init.sh
# 输入书名、主角、选择小说类型...

# 3. 在 Claude Code 中打开项目目录，说：
# "写第一章"
```

## 内置写作类型

| 类型 | 适用平台 | 核心驱动力 |
|------|----------|-----------|
| **爽文/升级流** | 番茄、起点 | 信息差碾压、快速打脸、升级期待 |
| **悬疑/解谜** | 起点、豆瓣阅读 | 好奇心、伏笔回收、反转冲击 |
| **情感/煽情** | 晋江、番茄女频 | 情绪价值、人物关系、刀糖交替 |
| **无限流/副本** | 起点、番茄 | 副本新鲜感、主线悬念、能力成长 |
| **日常/轻松** | 番茄、晋江 | 人设魅力、氛围感、单元剧 |
| **设定/规则创新** | 番茄、起点 | 新奇规则、设定驱动冲突、信息差 |
| **自定义** | 全部 | 你定义自己的规则，AI按你的规则写 |

## 管理三件套

| 文件 | 作用 |
|------|------|
| **章节目志** | 每章核心事件+伏笔记录 |
| **伏笔追踪表** | 所有伏笔的状态追踪 |
| **当前状态速查** | 主角状态+进度快照 |

每次续写，AI自动读取→写章节→更新三件套。写完说"检查管理文档"，AI复核一致性。
