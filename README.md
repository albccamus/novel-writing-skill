# Novel Writing Skill

**在 Claude Code 里写长篇小说？你只需要说"续写10章"。**

---

## 这是什么

一个基于 Claude Code 的长篇网文写作工作流模板。它把写小说这件事变成了三个步骤：

1. 跑一个脚本，填书名/主角/选类型
2. 在 Claude Code 里打开目录
3. 说：**"写第一章"**

之后每次只要说"续写10章"，AI 就会自动读进度→写章节→更新管理表→清理格式。

不需要每次重新交代设定。不需要担心写到后面忘了前面的伏笔。

---

## 为什么会有这个东西

写长篇最大的痛点不是灵感，是**连贯性**。前面埋的伏笔到后面忘了收、配角性格写飘了、时间线对不上——这些问题在长篇连载中几乎不可避免。

这个项目把"外部记忆"做成了三个管理文件，让 AI 每次写作前先读进度，写完后更新状态。**相当于给 AI 装了一个专用记事本。**

---

## 快速开始

```bash
# 1. 下载
git clone https://github.com/albccamus/novel-writing-skill.git
cd novel-writing-skill

# 2. 初始化项目
bash scripts/init.sh

# 3. 回答几个问题（书名、主角、选类型...）
#    自动生成 CLAUDE.md + 管理模板 + 设定集骨架

# 4. 用 Claude Code 打开这个目录，说：
#    "写第一章"
```

往后只需要说"续写10章"，或者"检查管理文档"让 AI 复核一致性。

## 内置写作类型

不同的小说类型有完全不同的写作规律——爽文的节奏是每3章一个打脸，悬疑是每章结尾扔钩子，情感是先给糖再给刀。这个项目内置了 6 种类型的完整写作规则，初始化时选一个就行。

| 类型 | 适合平台 | 一句话 |
|------|----------|--------|
| **爽文/升级流** | 番茄、起点 | 打脸要快，升级要稳，信息差碾压 |
| **悬疑/解谜** | 起点、豆瓣 | 信息挤牙膏，伏笔不白埋，反转有铺垫 |
| **情感/煽情** | 晋江、番茄女频 | 糖要甜够，刀要合理，留白比说破有力 |
| **无限流/副本** | 起点、番茄 | 副本独立成章，主线暗中推进 |
| **日常/轻松** | 番茄、晋江 | 人设就是剧情，角色互动决定一切 |
| **设定/规则创新** | 番茄、起点 | 设定的限制比能力更重要 |
| **自定义** | 全部 | 你定规则，AI 按你的规则写 |

## 管理三件套

```
写作管理_章节目志.md       # 每章核心事件 + 伏笔记录
写作管理_伏笔追踪表.md     # 所有伏笔的埋设/回收状态
写作管理_当前状态速查.md   # 主角状态 + 进度快照
```

三个文件构成小说的"外部记忆"。每次续写，AI 自动读取、写完后自动更新。写累了说一句"检查管理文档"，AI 自己复核三张表是否一致。

## 项目结构

```
novel-writing-skill/
├── README.md                        # 你正在看这个
├── scripts/
│   └── init.sh                      # 初始化脚本（填信息 + 选类型）
└── template/
    ├── CLAUDE.md                    # 工作流指令 + 6种类型写作规则
    ├── 完整作品设定集.md            # 设定集骨架模板
    ├── 写作管理_章节目志.md         # 章节记录表（空白模板）
    ├── 写作管理_伏笔追踪表.md       # 伏笔管理表（空白模板）
    ├── 写作管理_当前状态速查.md     # 进度快照（空白模板）
    └── .claude/
        └── settings.local.json      # 权限预配
```


写完直接复制到发文平台，或继续在本地编辑。
